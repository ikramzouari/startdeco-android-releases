# StartDeco Android Releases

Official public Android release downloads for StartDeco.

## Installation

1. Open the latest release.
2. Download the `.apk` file.
3. On Android, authorize installation from the browser when prompted.
4. Install and open StartDeco.

The application package is `tn.startdeco.app`. Release checksums are published
with each version.

Source code, signing keys, credentials, and production secrets are not stored
in this repository.
